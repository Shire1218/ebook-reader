# 墨卷（Inking）桌面应用原型开发计划书

## 一、项目概述

### 1.1 项目背景
基于现有的墨卷（Inking）Web 电子书阅读器应用，在 `e:\chrome\book\prototype\` 目录下开发一个简单的桌面应用原型，保留系统的核心功能，验证桌面化可行性。

### 1.2 开发目标
- 保留现有系统的基本功能
- 实现简单的桌面应用封装
- 验证 Electron 桌面化方案的可行性
- 为后续完整桌面应用开发提供基础

### 1.3 核心原则
- **功能保留**：100% 保留现有 Web 端核心功能
- **简单实现**：采用最简方案，快速验证
- **代码复用**：最大化复用现有前端代码
- **渐进开发**：先实现基础框架，再逐步完善

## 四、开发步骤

### 4.1 第一阶段：基础框架搭建（1-2天）

#### 步骤 1：初始化项目
- 创建 `prototype` 目录结构
- 初始化 `package.json`
- 安装核心依赖：`electron`, `electron-builder`, `vite`

#### 步骤 2：配置 Electron 主进程
- 创建 `electron/main.ts`：主进程入口
- 创建 `electron/preload.ts`：预加载脚本
- 配置窗口管理（窗口大小、标题、图标）

#### 步骤 3：配置构建工具
- 配置 `vite.config.ts`：适配 Electron 环境
- 配置 `electron-builder.config.js`：打包配置
- 配置 `tsconfig.json`：TypeScript 配置

### 4.2 第二阶段：前端代码迁移（2-3天）

#### 步骤 4：复制前端代码
- 复制现有 `src/` 目录到 `prototype/src/`
- 调整导入路径（如有必要）
- 验证前端代码在 Electron 环境下正常运行

#### 步骤 5：配置平台适配层
- 创建 `src/platform/` 目录
- 实现环境检测：`src/platform/detect.ts`
- 实现 Web 端适配：`src/platform/web.ts`
- 实现 Electron 端适配：`src/platform/electron.ts`

#### 步骤 6：集成 IPC 通信
- 实现基本 IPC 通道：文件对话框、文件系统操作
- 配置 preload 脚本暴露 API
- 测试主进程与渲染进程通信

### 4.3 第三阶段：功能验证与优化（2-3天）

#### 步骤 7：核心功能验证
- 验证书籍导入功能（EPUB/PDF/TXT/MOBI）
- 验证阅读器功能（各种格式）
- 验证书签、高亮、进度保存功能
- 验证用户登录/注册功能

#### 步骤 8：桌面特性增强
- 实现原生菜单栏
- 实现文件关联（双击打开书籍文件）
- 实现系统托盘（可选）

#### 步骤 9：打包与测试
- 配置打包脚本
- 生成 Windows 安装包
- 测试安装包功能完整性

### 4.4 第四阶段：文档与交付（1天）

#### 步骤 10：编写文档
- 编写开发文档
- 编写使用说明
- 整理测试报告

## 五、关键技术点

### 5.1 环境检测
```typescript
// src/platform/detect.ts
export const isElectron = () => {
  return typeof window !== 'undefined' && 
         typeof window.electronAPI !== 'undefined';
};
```

### 5.2 平台适配
```typescript
// src/platform/index.ts
import { isElectron } from './detect';
import { webPlatform } from './web';
import { electronPlatform } from './electron';

export const platform = isElectron() ? electronPlatform : webPlatform;
```

### 5.3 IPC 通信
```typescript
// electron/preload.ts
import { contextBridge, ipcRenderer } from 'electron';

contextBridge.exposeInMainWorld('electronAPI', {
  openFileDialog: () => ipcRenderer.invoke('dialog:openFile'),
  readFile: (path: string) => ipcRenderer.invoke('fs:readFile', path),
  // ... 其他 API
});
```
